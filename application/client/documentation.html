Description and documentation

Gerard's Order Management App is the application used by the sales staff of our European chain of electronics stores to register customer orders and look them up later. All orders are saved on the server, which is also where prices are calculated.

To use the application you have to log in first with your username and password. Both fields are required. If the user cannot be validated, an error message is shown and you are taken back to the start page.

After logging in, the operations menu lets you choose one of these operations and open it with the Go button:

Create a new order

Fill in the order ID and the customer's details: full name, address, email address and phone number. Then tick the products the customer wants to buy and enter the quantity of each one (the quantity box is only enabled when the product is ticked). Click Send order and the server will calculate the total price of the order with VAT (21%), save the order and send back the total, which is shown below the form.

View orders

Choose one of the two options and click Go:

  • View all orders: shows a table with all the data of every saved order.
  • View one order: enter the ID of an order and click Search to see a table with all the data of that order. If there is no order with that ID, an error message is shown.

If the orders file cannot be found or opened, an error message is shown instead.
